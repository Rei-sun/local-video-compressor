# local-video-compressor

動画の必要な範囲を切り出し、Discordで送りやすいサイズに圧縮するツールです。

## 使い方

1. 動画を選ぶか、画面にドラッグ＆ドロップします。
2. 再生バーや範囲のハンドルを使って、使う部分を選びます。
3. 目標サイズと画質を選び、「圧縮をはじめる」を押します。圧縮中は同じボタンからキャンセルできます。
4. 完了したら「ダウンロード」を押して保存し、Discordのチャットに添付します。

目標サイズは1〜20 MBで設定できます。動画が目標サイズに収まらない場合は、範囲を短くするか画質を下げてください。

## ファイルとプライバシー

動画の読み込み、再生、トリミング、圧縮はブラウザ内で行います。動画ファイルはサーバーにアップロードされません。Discordへの投稿もこのツールからは行わず、圧縮した動画をダウンロードして添付します。

圧縮エンジンの読み込みにはインターネット接続が必要です。動画の長さや端末の性能によって、圧縮に時間がかかったり、ブラウザのメモリを多く使ったりすることがあります。
